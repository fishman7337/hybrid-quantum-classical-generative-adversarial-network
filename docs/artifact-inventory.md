# Artifact Inventory

## Notebooks

- `notebooks/Quantum-GAN.ipynb`: exploratory classical GAN notebook for binary
  MNIST. Markdown structure has been added for readability and review.
- `notebooks/legacy/DELE_CA2_C.ipynb`: legacy notebook preserved from the
  original GitHub repository.

## Paper Source Bundles

- `papers/singapore-polytechnic-ca2/`: school assessment submission source
  package, including LaTeX sources, figures, and `main.pdf`.
- `papers/arxiv-source/`: arXiv source package for the public paper, including
  IEEE LaTeX sources, figures, and `2508.09209v2.pdf`.
- `papers/arxiv-source/HQCGAN-arXiv-2508.09209v1.pdf`: arXiv PDF artifact
  preserved from the original GitHub repository.

## Generated Artifacts

Local generated artifacts should be placed in:

- `models/` for checkpoints
- `reports/figures/` for generated plots
- `reports/` for summaries and exported evaluation tables
