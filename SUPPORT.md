# Support

For academic questions, start with the paper, notebook, and documentation in
this repository:

- `README.md` for orientation
- `docs/reproducibility.md` for environment and run guidance
- `docs/research-context.md` for institutional and paper provenance
- `papers/` for preserved source archives

For technical issues, include the operating system, Python version, installed
extras, command used, and the full error message.
